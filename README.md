## About Me

I am a **Bachelor of Information Technology (Hons)** student at **Universiti Teknologi PETRONAS (UTP)** with strong foundations in **network automation, enterprise troubleshooting, software engineering, data analytics, and quality assurance**.

Through my 8-month dual internship at **SLB** in the Enterprise Management Center and academic engineering projects, I have developed the ability to diagnose complex enterprise network issues, automate operational workflows, and build data-driven decision-support systems.

My hands-on experience spans **network orchestration and troubleshooting, machine learning predictive modeling, BI dashboard development, and automated API/unit testing**. These experiences strengthened my analytical problem-solving, technical adaptability, and precision in delivering reliable systems.

* **Network & Enterprise Automation:** Equal proficiency in hands-on network troubleshooting and building automated workflows using OpenText Operations Orchestration, Python, Power Automate, and Power Apps.
* **Data Analytics & Machine Learning:** Experienced in developing predictive machine learning models, ETL pipelines (Azure Data Factory, SQL), and interactive visualization dashboards using Streamlit and Power BI.
* **Software Engineering & QA:** Skilled in designing software architectures (UML, SDD) and enforcing code quality through automated REST API and unit testing (`pytest`, `ruff`).

> **Current Mission:** To leverage enterprise networking, automation, and AI-driven data analytics to solve real-world operational bottlenecks and build resilient, high-impact software systems.
